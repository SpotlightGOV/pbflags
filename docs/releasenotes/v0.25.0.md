# pbflags v0.25.0

This release improves the flag management UI with better visibility into default values and streamlines the release process.

## UI Improvements

- Flag detail pages now show the compiled default value when an otherwise condition masks it, so operators always know the SDK fallback
- Killed flags with a masked default show a prominent banner with the actual value SDKs will return
- The compiled default hint also appears when the otherwise row has a runtime override

## Infrastructure

- Release process now supports non-interactive mode with `INTERACTIVE=false` option for automated builds
